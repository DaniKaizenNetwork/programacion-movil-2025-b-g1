# Data Base – Información General

Este proyecto front-end depende de una base de datos relacional gestionada por el backend (no incluida en este repositorio). Se documenta el modelo esperado para que los equipos puedan mantener sincronizados los esquemas.

Archivos:
- `schema.md`: descripción textual de tablas y campos.
- `erd.md`: representación visual (Mermaid) del modelo entidad-relación.
